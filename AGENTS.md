# Alphonse Afanyu Portfolio

React + Next.js App Router landing page intended for Vercel deployment.

## Development

- `npm run dev` starts the local Next.js server.
- `npm run build` creates and validates the production build.
- `npm run start` serves the production build.
- `npm run check` runs TypeScript without emitting files.

## Structure

- `app/layout.tsx` — global metadata and document layout.
- `app/page.tsx` — landing-page route.
- `app/globals.css` — global styling and reduced-motion behavior.
- `app/robots.ts` and `app/sitemap.ts` — SEO metadata routes.
- `src/App.tsx` — interactive React landing-page sections.
- `src/index.css` — visual system and responsive styles.
